# Monetree
Monetree is a SaaS platform that allows creators, freelancers, and influencers to build a single monetized link page. Users can add links, sell services, and share payment or booking options through one public profile.  Customers discover Monetree through social media and online communities.

## Landing page

This repository now includes a simple static landing page for Monetree, built with plain HTML and CSS.

- `index.html`: page structure and content
- `styles.css`: visual styles and responsive layout
- `vercel.json`: minimal Vercel configuration
